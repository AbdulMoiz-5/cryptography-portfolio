# Cryptography Portfolio

A practical cryptography portfolio covering classical cryptography, number theory, modular arithmetic, RSA with the Chinese Remainder Theorem, cryptanalysis, algebraic foundations, and AES concepts.

## Highlights

- Classical cryptography: Caesar, Vigenère, XOR, and brute-force analysis
- Number theory: GCD, extended GCD, modular inverses, discrete logarithms
- RSA optimization: CRT-based decryption and Garner's algorithm
- Cryptanalysis: brute-force search, frequency-analysis concepts, quadratic residues, and Tonelli-Shanks
- AES concepts: key expansion, S-boxes, SubBytes, MixColumns, and round structure
- Mathematical foundations: groups, rings, units, and fields

## Repository structure

```text
docs/                 Concept notes and lab write-ups
src/number-theory/    Number-theory implementations
src/crt-rsa/          CRT, RSA-CRT, and Garner implementations
src/cryptanalysis/    Cryptanalysis exercises
notes/                Short portfolio notes
tests/                Small correctness checks for the included Python examples
```

## Source material

The original university submission files were intentionally not copied into this repository. Student roll numbers, instructor details, assignment formatting, duplicate exports, and scanned/low-value submission artifacts were removed so the work is presented as a technical portfolio.

Where the original material contained only screenshots or scanned pages without reusable source code, this repository documents the demonstrated concept rather than inventing source code that was not provided.

## Tools and concepts

- Python
- SageMath / symbolic-math concepts
- Modular arithmetic
- RSA / CRT
- Classical cryptanalysis
- AES concepts
- Number theory and finite-field foundations

> **Educational note:** The Python implementations are intended for learning and demonstration. They are not replacements for vetted cryptographic libraries in production systems.
