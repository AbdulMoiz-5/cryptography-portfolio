# Algebra for Cryptography

The submitted work covers the mathematical structures used in cryptography.

- **Set:** a collection of elements.
- **Group:** a set with a binary operation satisfying closure, associativity, identity, and inverse properties.
- **Ring:** a set with addition and multiplication satisfying the ring axioms.
- **Units:** elements that have multiplicative inverses. In `Z_n`, an element is a unit exactly when `gcd(a, n) = 1`.
- **Field:** `Z_n` is a field when `n` is prime, because every non-zero element then has a multiplicative inverse.

These structures are foundational to modular arithmetic, public-key cryptography, and finite-field algorithms.
