# Number Theory and Modular Arithmetic

Practical exercises covered:

- Euclidean and extended Euclidean algorithms
- Modular reduction
- Fermat's Little Theorem
- Modular inverses
- Quadratic residues and roots
- Tonelli-Shanks algorithm
- Chinese Remainder Theorem
- Garner's algorithm

Examples in the original lab include `gcd(66528, 52920) = 1512`, `3⁻¹ mod 13 = 9`, and a CRT system solved to `x = 872`.

The source implementations are provided under `src/number-theory/` and `src/crt-rsa/`.
